# 01-ts-basics

Домашнє завдання №1 — основи TypeScript: типізація даних, функцій та асинхронних операцій.

| Файл            | Тема                                             |
| --------------- | ------------------------------------------------ |
| `src/task-1.ts` | Прості типи: `string`, `number`, `boolean`       |
| `src/task-2.ts` | Інтерфейс, `readonly` та опціональні поля        |
| `src/task-3.ts` | Масиви `тип[]` та масив об'єктів                 |
| `src/task-4.ts` | Типізація функцій, опціональний параметр, `void` |
| `src/task-5.ts` | Union Type                                       |
| `src/task-6.ts` | Generics                                         |
| `src/task-7.ts` | `Promise<T>`                                     |
| `src/task-8.ts` | HTTP-запит з Axios                               |

## Запуск

```bash
npm install
npm run dev        # результати — у консолі браузера
npm run typecheck  # перевірка TypeScript
npm run format     # форматування Prettier
```
